## Overview

Han Eap Simulator Web UI is the frontend for a semiconductor equipment automation simulation system. It supports SECS/GEM and HSMS integration workflows, including engine management, SML message maintenance, manual SECS operations, auto-reply rules, visual Flow orchestration, and Checklist-driven SML/Flow generation.

This repository contains only the frontend source code. Backend services, database migrations, seed data, checklist templates, and complete application distributions are maintained separately.
